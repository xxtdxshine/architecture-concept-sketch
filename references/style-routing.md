# 单一表达语言与画材路由

以下针对用户图片，不代表建筑师完整风格。先选主语言，再分别用钢笔和炭笔转译。表中默认画材为第一版的适配参考，不减少双稿交付，也不额外生成铅笔稿。用户点名优先，但不可把输入改成参考建筑。

|可见构成|参考|默认画材|画法|
|曲面折叠、片状屋顶、多体块交叠|Gehry-1/3/6|钢笔|少量长回环串体量，开放轮廓，复线集中在交接|
|塔楼退台、竖向褶皱、叠置|Gehry-2/4|铅笔|建立高度层级，轻重试探线表达竖向摆动，省网格|
|倾斜直面、体块碰撞、深空隙|Gehry-5/董功|炭笔|几个块体、关键暗部、颗粒侧锋，大量留白|
|纯几何、墙体切入、光缝|Ando-1/2|铅笔|几何秩序与反复找线，不扭成曲面|
|建筑与地形树木耦合|Siza-1/2|钢笔|少量地形线定位，小图表达空间关系|
|层叠连续带、水平延展|隈研吾|炭笔|宽窄交替断续层带，保持层间空隙，不用水墨笔刷|
|连续扭转、方向汇聚|Zaha|钢笔|沿真实运动方向组织回旋，不画全幅无关圆环|

笔触示例：钢笔用长弧→回折→断线，阴影只用稀疏排线，禁止灰色擦抹。铅笔用浅试探线→深确认线→少量短斜线，全图石墨质感，禁止叠墨线。炭笔用颗粒轮廓→侧锋暗部→同材质尖线，留白主导，禁止钢笔勾边。

每条回环解释折叠，每束复线解释转折，每处暗部解释空隙，没有对应关系的画痕应删除。


炭笔的优先笔触标尺为用户指定的 images/隈研吾.jpg，适用于各种建筑构成的炭笔转译。用少量宽厚侧锋与颗粒黑带表达体量，允许关键带面形成明确黑块，黑白留空交替；细尖线从属，避免钢笔式密集描边。具体取舍见 approved-style.md 的炭笔稿专用标尺。
