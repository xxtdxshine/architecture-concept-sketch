# 作品—图稿补充来源

核查日期：2026-09-05。以下为独立补充案例，不把“找到了同一位作者的项目”当成本地图片精确溯源。保留链接与简短归纳，不复制网站全文或把媒体图片打包成自有素材。

## 已获得项目和图稿的明确来源

- **隈研吾 / V&A Dundee**：[官方建筑介绍](https://www.vam.ac.uk/dundee/info/our-building)、[官方设计过程展陈](https://www.vam.ac.uk/dundee/info/architectural-story-of-v-a-dundee-told-in-new-display)、[官方委托草图版画](https://shop.vandadundee.org/products/folio-2-kengo-kuma-limited-edition-print)。官方说明展陈包含概念草图与模型；版画页明确作者、项目和为开馆创作的草图。不能据版画载体推断原始画笔。用途：研究自然启发、两个体量与层叠关系；不是本地“隈研吾.jpg”的已确认身份。
- **西扎 / Boa Nova Tea House**：[SFMOMA 藏品 2005.242](https://www.sfmoma.org/artwork/2005.242/)、[CCA 速写本记录](https://www.cca.qc.ca/en/search/details/collection/object/524321)。SFMOMA 明确项目、建筑图类别和 ink on paper；CCA 搜索记录指向包含该项目的速写本，详情页本轮未成功加载。以 SFMOMA 为主要证据。用途：空间与场地细线推敲；不能反向确认 Siza-1/2 的项目。
- **董功 / 直向建筑海边教堂**：[事务所提供内容的 gooood 项目页](https://www.gooood.cn/seashore-chapel-china-by-vector-architects.htm)。同页包含建成照片和明确署名“设计手稿 ©直向建筑”的图注。可核查项目—图稿关系；本地“董功.jpg”未完成逐图同一性比对。用途：抬升实体与下部公共空隙的构成，避免把所有单体都归入同一项目。
- **安藤 / 光之教堂**：[MoMA 展览图录](https://www.moma.org/documents/moma_catalogue_348_300085246.pdf)。检索可定位 Church of the Light 与 Sketch；这是补充核查入口，未完成本地 Ando-2 与图录逐页同一性验证。用途：几何墙体、斜向切入和光的空间关系；不能从一张外观照片直接恢复真实平面。
- **扎哈 / Vitra Fire Station**：[Zaha Hadid Foundation 藏品与建成照片](https://www.zhfoundation.com/collections/vitra-fire-station/)。同页分别标明 Corridor、Aerial site plan 图绘及建成照，原媒介为 Acrylic on cartridge；**不是允许直接模仿的铅笔/钢笔/炭笔画材范例**。只补充片墙碰撞、层叠与方向组织的方法，转译时仍限一种黑白画材。不能把本地 Zaha.jpg 当成 Vitra 草稿。

## 盖里补充

[MoMA 艺术家与馆藏入口](https://www.moma.org/collection/artists/2108)列有 Fishdance Restaurant 外观透视草图等；[MOCA 的 Work in Progress 展览](https://www.moca.org/exhibitions/frank-o-gehry-work-in-progress)描述原始草图、研究模型与后续设计过程。用于理解草图为构想推敲，而非把建成照描边。具体六张本地拼图仍按 reference-catalog 的置信状态使用。
